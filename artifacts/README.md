# Generated artifacts

Training outputs are intentionally not committed to the repository. Local runs write checkpoints, predictions, metrics, manifests, and reports here; checkpoints and prediction bundles are ignored because they are large.

The public, compact benchmark summary is maintained in [`docs/v3-comparison.md`](../docs/v3-comparison.md), [`docs/benchmarks.csv`](../docs/benchmarks.csv), and the SVG graphs in `docs/`.
